# Rotate Rings

Later game; rules to define with Adrien (screenshots of the version he has in
mind) before any work.

Likely shape: concentric rings, each split into coloured or patterned
segments, rotated by dragging; the goal is to line the segments up (a picture,
or one colour per radial slice). Variants exist where rotating one ring turns
a neighbour too, which is what makes it a puzzle rather than a sorting chore.
Generation by scrambling a solved state with random rotations, so it is
always solvable; difficulty by the number of linked rings.
