# Game ideas

Candidates for later, in the same spirit: solo, short sessions, generated and
always solvable. Adding one is Adrien's call; then it gets a
`docs/games/<game>.md` and a plan step.

| Game | In one line | Why it fits |
|---|---|---|
| Nonogram (picross) | Shade cells from row and column number clues to reveal a picture | Generator + logical solver like Stars |
| Minesweeper, no guessing | Every board solvable by logic alone (Tatham's "Mines") | Fixes the classic's worst moment |
| Flow / Numberlink | Join pairs of same-colour dots with paths filling the whole grid | Close to Color Dots' audience, generator by path growth |
| Bridges (Hashi) | Link islands with 1 or 2 bridges to match their numbers | Small, elegant, logic only |
| Tents | Place one tent beside each tree, row/column counts | Same family as Stars |
| Light Up (Akari) | Place bulbs to light every cell, numbered walls | Same family as Stars |
| Sudoku and Killer Sudoku | The classics, with a technique-graded generator | Expected in such a collection |
| 2048 | Merge tiles up to 2048 | Zero rules to learn, a good "relax" game |
| Lights Out | Toggle a cell and its neighbours until all are off | Tiny, solvable by linear algebra over GF(2) |
| Sokoban | Push boxes onto targets | Handmade or generated levels, deeper puzzles |
| FreeCell / Spider | Two more solitaires on Klondike's card engine | Reuses the cards, almost every FreeCell deal is winnable |
